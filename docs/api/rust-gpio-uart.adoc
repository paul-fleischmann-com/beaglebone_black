== Übersicht

Die Rust Hardware Library (`libhardware_rs.so`) stellt Memory-Safe Implementierungen der Hardware-Treiber bereit.
Alle öffentlichen Funktionen sind als `extern "C"` mit `#[no_mangle]` exportiert und direkt aus Go via FFI aufrufbar.

Compile-Target: `armv7-unknown-linux-musleabihf`

Quellen:

* `project/rust-lib/src/gpio.rs`
* `project/rust-lib/src/uart.rs`

== GPIO Treiber

=== Typdefinitionen

==== RsGpioData

Rückgabestruktur für GPIO-Operationen. C-kompatibel (`#[repr(C)]`).

[source,rust]
----
#[repr(C)]
pub struct RsGpioData {
    pub pin:   u32,  // GPIO-Pin-Nummer
    pub value: i32,  // Gelesener Wert: 0 = LOW, 1 = HIGH
    pub error: i32,  // 0 = Erfolg, -1 = Fehler
}
----

=== FFI-Exports

==== rs_gpio_export

Exportiert einen GPIO-Pin über `/sys/class/gpio/export`. Wartet 100ms nach dem Export damit das sysfs-Interface bereit ist.

[source,rust]
----
#[no_mangle]
pub extern "C" fn rs_gpio_export(pin: u32) -> c_int
----

[cols="1,1,3", options="header"]
|===
| Parameter | Typ | Beschreibung
| pin | u32 | GPIO-Pin-Nummer
|===

*Rückgabe:* `0` bei Erfolg, `-1` bei Fehler

==== rs_gpio_set_direction

Setzt die Richtung eines GPIO-Pins via `/sys/class/gpio/gpio{pin}/direction`.

[source,rust]
----
#[no_mangle]
pub extern "C" fn rs_gpio_set_direction(pin: u32, output: c_int) -> c_int
----

[cols="1,1,3", options="header"]
|===
| Parameter | Typ | Beschreibung
| pin | u32 | GPIO-Pin-Nummer
| output | c_int | `1` = Ausgang (`"out"`), `0` = Eingang (`"in"`)
|===

*Rückgabe:* `0` bei Erfolg, `-1` bei Fehler

==== rs_gpio_read

Liest den aktuellen Wert eines GPIO-Pins von `/sys/class/gpio/gpio{pin}/value`.

[source,rust]
----
#[no_mangle]
pub extern "C" fn rs_gpio_read(pin: u32) -> RsGpioData
----

[cols="1,1,3", options="header"]
|===
| Parameter | Typ | Beschreibung
| pin | u32 | GPIO-Pin-Nummer
|===

*Rückgabe:* `RsGpioData` mit `value = 0/1` und `error = 0` bei Erfolg, `error = -1` bei Fehler

==== rs_gpio_write

Schreibt einen Wert auf einen GPIO-Ausgangspin via `/sys/class/gpio/gpio{pin}/value`.

[source,rust]
----
#[no_mangle]
pub extern "C" fn rs_gpio_write(pin: u32, value: c_int) -> c_int
----

[cols="1,1,3", options="header"]
|===
| Parameter | Typ | Beschreibung
| pin | u32 | GPIO-Pin-Nummer
| value | c_int | `1` = HIGH, `0` = LOW
|===

*Rückgabe:* `0` bei Erfolg, `-1` bei Fehler

'''

== UART Treiber

=== Typdefinitionen

==== RsUartHandle

Handle für eine geöffnete serielle Verbindung. Enthält einen rohen Zeiger auf das `SerialPort`-Objekt. C-kompatibel (`#[repr(C)]`).

[source,rust]
----
#[repr(C)]
pub struct RsUartHandle {
    pub port: *mut Box<dyn SerialPort>,  // null = nicht geöffnet
}
----

WARNING: `RsUartHandle` muss nach Verwendung mit `rs_uart_close` freigegeben werden um Memory Leaks zu vermeiden.

==== RsUartData

Rückgabestruktur für empfangene UART-Daten. C-kompatibel (`#[repr(C)]`).

[source,rust]
----
#[repr(C)]
pub struct RsUartData {
    pub buf:   [u8; 256],  // Empfangspuffer (maximal 256 Bytes)
    pub len:   u32,         // Anzahl tatsächlich empfangener Bytes
    pub error: i32,         // 0 = Erfolg, -1 = Fehler
}
----

=== FFI-Exports

==== rs_uart_open

Öffnet die serielle Schnittstelle mit 100ms Timeout.

[source,rust]
----
pub unsafe extern "C" fn rs_uart_open(port: *const c_char, baud: u32) -> RsUartHandle
----

[cols="1,1,3", options="header"]
|===
| Parameter | Typ | Beschreibung
| port | *const c_char | Gerätepfad als C-String z.B. `"/dev/ttyO1"`
| baud | u32 | Baudrate z.B. `115200`
|===

*Rückgabe:* `RsUartHandle` mit gültigem `port`-Zeiger bei Erfolg, `port = null` bei Fehler

==== rs_uart_write

Sendet Bytes über die serielle Schnittstelle.

[source,rust]
----
pub unsafe extern "C" fn rs_uart_write(
    h: *mut RsUartHandle,
    buf: *const u8,
    len: u32
) -> c_int
----

[cols="1,1,3", options="header"]
|===
| Parameter | Typ | Beschreibung
| h | *mut RsUartHandle | Geöffnetes UART-Handle
| buf | *const u8 | Zeiger auf Sendedaten
| len | u32 | Anzahl der zu sendenden Bytes
|===

*Rückgabe:* Anzahl gesendeter Bytes, `-1` bei Fehler oder null-Handle

==== rs_uart_read

Empfängt bis zu 256 Bytes von der seriellen Schnittstelle.

[source,rust]
----
pub unsafe extern "C" fn rs_uart_read(h: *mut RsUartHandle) -> RsUartData
----

[cols="1,1,3", options="header"]
|===
| Parameter | Typ | Beschreibung
| h | *mut RsUartHandle | Geöffnetes UART-Handle
|===

*Rückgabe:* `RsUartData` mit empfangenen Bytes. `error = -1` bei Fehler oder null-Handle.

==== rs_uart_close

Schließt die Verbindung und gibt den Heap-Speicher des `SerialPort`-Objekts frei.

[source,rust]
----
pub unsafe extern "C" fn rs_uart_close(h: *mut RsUartHandle)
----

NOTE: Setzt `h.port` auf `null` nach dem Schließen. Mehrfaches Aufrufen ist sicher.

=== Verwendungsbeispiel (aus Go via FFI)

[source,go]
----
// #include "hardware_rs.h"
// import "C"

handle := C.rs_uart_open(C.CString("/dev/ttyO1"), 115200)
if handle.port == nil {
    return errors.New("UART öffnen fehlgeschlagen")
}
defer C.rs_uart_close(&handle)

// Senden
msg := []byte("Hello")
C.rs_uart_write(&handle, (*C.uint8_t)(&msg[0]), C.uint32_t(len(msg)))

// Empfangen
data := C.rs_uart_read(&handle)
if data.error == 0 {
    received := C.GoBytes(unsafe.Pointer(&data.buf[0]), C.int(data.len))
    fmt.Printf("Empfangen: %s\n", received)
}
----
